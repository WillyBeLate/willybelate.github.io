WillyBeLate Pipeline

Personal desktop tool for the creator WillyBeLate

WillyBeLate Pipeline is a private desktop application that prepares the creator's own gaming clips and sends them as drafts to the creator's own TikTok account.

It runs only on the creator's Windows PC. It is not a public service and has no user accounts of its own.

How it works

  • The creator places their own recorded clips in a local folder.
  • The tool checks each video against TikTok's format requirements and formats it for vertical viewing.
  • The creator reviews the clip and approves it manually.
  • Only after approval, the video is uploaded as a draft to the creator's TikTok inbox.
  • The creator opens the draft in the TikTok app, edits it and decides whether to post it.

Nothing is ever published automatically. Every post is finished and published by the creator inside the TikTok app.
